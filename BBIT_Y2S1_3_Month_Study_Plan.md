## 2. Unit Breakdown — What to Concentrate On

Research sourced from MUST exam papers (CIT 3200, CCS 3200, CIT 3206, SSA 3120, CIT 3202, BFB 3150, BEC 3200, BFC 3226) — these are EXACTLY what lecturers test.

### CIT 3200 – Operating Systems (Stephen Mageto)
**Core:** How OS manages hardware/software/interface.
**High-Frequency Exam Areas (80% of marks):**
- Processes & Threads: 5-state model, PCB contents, process termination reasons
- CPU Scheduling: FCFS, SJF, RR, Priority, HRRN — Gantt charts + avg waiting/turnaround time calculations
- Concurrency: Race condition, mutual exclusion, semaphores, Producer-Consumer, Readers-Writers
- Deadlocks: 4 conditions (mutual exclusion, hold & wait, no preemption, circular wait), prevention/avoidance (Banker's), detection & recovery
- Memory Management: Paging, segmentation, virtual memory, page replacement (LRU, FIFO, Optimal), fragmentation, Best/Worst/First Fit allocation
- File & I/O: File attributes, directory structures, spooling, protection/authentication
- Past-paper tip: Draw labeled diagrams (5-state, layered OS, monolithic vs microkernel, resource allocation graph)

**Concentrate:** Scheduling calculations + Deadlock numericals + LRU page faults — always 20 marks.

### CCS 3200 – Data Structures and Algorithms (Patrick Njuguna)
**Core:** ADT + efficiency.
**Key Areas:**
- ADT Concepts: Abstraction, encapsulation, 2 elements of data type implementation
- Linear: Stack (push/pop, postfix conversion), Queue (circular queue, DE queue, priority queue, array vs pointer efficiency), Linked Lists (single, circular, double)
- Non-Linear: Trees (binary vs general, traversals: inorder/preorder/postorder), BST insertion/deletion, Heap insert/remove, Graphs (BFS/DFS - basic)
- Algorithms: Recursion, Sorting (Insertion, Heap Sort, Bubble, Quick conceptually), Searching (Binary/Linear)
- Analysis: Big O (time/space), Algorithm characteristics, Complexity types
- Practical: Write algorithm to count nodes, construct BST, convert infix `(a-b/c)+d*e` to postfix, heap sort array `[30 20 6 15 8 3 4]`

**Concentrate:** Tree traversals + Stack/Queue applications + Sorting step-by-step working + Big O — examiners demand *show all working*.

### BFB 3150 – Insurance and Risk Management (Dr. Virginia Wachira)
**Core:** Risk vs Insurance Management.
**Key Areas:**
- Risk: Definition, types (pure vs speculative, financial risks), identification sources (checklists, financial statements, flow charts, inspections, experts)
- Risk Management Process: Identification → Evaluation → Treatment (avoidance, retention, reduction, transfer) → Implementation
- Principles of Insurance: Insurable interest, utmost good faith, indemnity, subrogation, contribution, proximate cause — *with Grace-like case studies*
- Policy Components: Declarations, insuring agreement, exclusions, conditions, premium
- Insurance Transactions & Claims: Why claims denied, underwriting, reinsurance, pro-rata liability
- Risk Manager roles & Enterprise Risk Management

**Concentrate:** Principles with examples + 4-step RM process + Claim denial reasons — 30-mark Q1 always asks these.

### CIT 3206 – Statistical Programming (David Kibaara)
**Core:** Python + R for statistics.
**Key Areas:**
- Python Basics: Variables (int/float/string/list), reserved keywords, interpreted vs compiled, hello world, operators
- Control: if/for/while, functions, arrays/lists vs tuples
- OOP: Inheritance, polymorphism, classes
- Libraries: NumPy, Pandas, Matplotlib, SciPy, StatsModels
- File/DB: I/O files, CSV, database connection
- Stats Tasks: Descriptive stats, linear regression (regression equation, prediction, correlation), vowels count function, listing keywords, trend/forecasting
- R Basics: vector, data frames (comparison with Python)

**Concentrate:** Code execution — exam is *practical*: Write runnable Python snippets (30% marks) + explain outputs.

### SSA 3120 – Probability and Statistics (NICHOLAS MUGAMBI)
**Core:** Descriptive → Inferential.
**Key Areas:**
- Descriptive: Measures central tendency (mean/median/mode - weighted mean: final×4 + midterm×3), dispersion, skewness, data types
- Probability: Sample space, distributions (normal, binomial), sum of two dice divisible by 3 etc., probability vs non-probability sampling
- Inference: Sampling methods, point/interval estimation, hypothesis testing (z/t), confidence intervals
- Correlation/Regression: Pearson’s r, regression lines (`y = a + bx`), prediction
- Past-paper tasks: Create probability distribution table, calculate coefficient of correlation

**Concentrate:** Weighted mean + Probability tables + Regression/correlation calculations — numerical accuracy matters.

### BEC 3200 – Principles of Macroeconomics (Titus Kirimi)
**Core:** Economy as a whole.
**Key Areas:**
- National Income: GDP (Y = C+I+G+NX), measurement, importance, circular flow (closed/open economy, 2/3/4 sector)
- Inflation & Unemployment: Types, CPI calculation, causes, Phillips curve
- Money & Banking: Demand for money theories (Keynesian), quantity theory, central bank functions
- Aggregate: AD-AS model, IS-LM basics, determinants of investment/consumption (consumption function)
- Policy: Fiscal (government spending/tax), Monetary (tools: OMO, reserve ratio), supply-side
- International: Exchange rate regimes, trade, balance of payments
- Growth: Long-run growth model, savings-investment

**Concentrate:** Circular flow diagram + CPI/inflation calculations + IS-LM explanation + National income stats importance — Q1 is always definitions with diagrams.

### BFC 3226 – Introduction to Financial Management (Samuel Mbogori)
**Core:** Manager’s finance decisions.
**Key Areas:**
- Objectives: Profit max vs shareholder wealth max, agency problem (shareholder-director conflict)
- Functions/Roles: Investment, financing, dividend decisions
- Financial Analysis: Statements, ratio analysis, working capital determinants
- Capital Budgeting: Payback, NPV, IRR, ARR, Profitability Index — *Project: cost 50k, inflows 20k×3yrs, 12% => calculate NPV/Payback*
- Sources of Finance: Equity vs debt finance advantages/disadvantages, cost of capital (WACC)
- Capital Structure & Dividend Policy, Financial planning & budgeting
- Risk-Return, Time value of money

**Concentrate:** Capital budgeting calculations (NPV/IRR/Payback) + Debt vs equity trade-offs + Working capital — 40% of exam is numerical.

### CIT 3202 – Network Design and Implementation (Eli Kangaru)
**Core:** Design → Configure → Troubleshoot.
**Key Areas:**
- Foundations: Network types by size (LAN/MAN/WAN/PAN), topologies (star, mesh, bus, hierarchical vs flat), OSI 7-layer & TCP/IP, encapsulation
- Devices: Hub vs Switch vs Router distinguishing features, Ethernet frame fields, CSMA/CD vs CSMA/CA
- IP: IPv4/IPv6, classes, subnetting (192.168.10.0/24 → 4 subnets), CIDR, VLSM, FLSM, network/broadcast IDs, valid hosts
- Routing: Static vs dynamic, routing algorithms & cost metrics, TCP 3-way handshake, TCP vs UDP choice, DHCP scenario
- Standards: IEEE 802.11 (WiFi), 802.3 (Ethernet), 802.1Q (VLAN)
- Design: Oppenheimer top-down approach, enterprise network stages, security vulnerabilities, performance indicators, SNMP, separate DB/app servers
- Commands: ping, nslookup, tracert, arp -a

**Concentrate:** Subnet chart creation + Static route configuration (R1-R2-R3 example) + OSI data forwarding + TCP handshake diagram.

## 5. Study Techniques per Unit Type

**For Numerical/Code Units (CIT 3200, CCS 3200, SSA 3120, BFC 3226, CIT 3202, CIT 3206):**
- Show ALL working (examiners award method marks). Practice Gantt, LRU, NPV on paper, not just reading.
- Code daily: Run Python in VS Code/Jupyter — even 5 lines for keywords/variables.
- Use spaced repetition: Day1 learn, Day3 recall, Day7 test.

**For Theory Units (BFB 3150, BEC 3200):**
- Mnemonics: e.g., Insurance principles = **"I GUIS CP"** (Insurable interest, Good faith, Utmost, Indemnity, Subrogation, Contribution, Proximate)
- Draw diagrams from memory weekly (circular flow, risk process, AD-AS).
- Teach: Explain to a friend / record voice note.

**For All:** 50-10 Pomodoro, 7hrs sleep, past papers > notes (60% time on papers in last month).
